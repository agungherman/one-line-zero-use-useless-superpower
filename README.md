One original line about a hilariously useless superpower, written for make.fun's "One Line, Zero Use: The Useless Superpower Sprint" bounty: teleport anywhere on Earth, but only three inches to the left, and only on Tuesdays.

## Run it

```sh
python3 main.py
```

The program writes the single line to `/output/entry.txt`.
